# Icon sources

- Technology brand icons in `public/brand-icons/` (except the Simple Icons files below): [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0), [MIT notice](DEVICON_LICENSE.txt).
- Monochrome brand marks (including Instagram, LangChain, Ollama, Ultralytics, and OpenTelemetry): [Simple Icons](https://github.com/simple-icons/simple-icons), [CC0 notice](SIMPLE_ICONS_LICENSE.md).
- Microsoft Foundry, Foundry Agent Service and the additional Azure service icons: [Microsoft Azure Architecture Icons](https://learn.microsoft.com/en-us/azure/architecture/icons).
- AWS service marks and Seaborn: [SVG Logos](https://github.com/gilbarbara/logos), CC0.
- MCP wordmark: [Model Context Protocol](https://github.com/modelcontextprotocol/modelcontextprotocol/tree/main/docs/logo).
- The existing paired light/dark stack icons and interface glyphs are retained from the template. Logos identify their respective technologies and issuers and do not imply affiliation.
